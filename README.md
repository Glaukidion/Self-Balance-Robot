# Self-Balance-Robot
Trata-se de um robô do tipo pêndulo invertido com apenas duas rodas. Sendo um
sistema naturalmente instável; para atingir o equilibre do mesmo, desenvolveu-se um sistema de controle de
estabilização e velocidade utilizando o microcontrolador Arduino nano. A aquisição de dados ocorreu mediante uso de
sensor acelerômetro/Giroscópio(MPU 6050), e como atuadores se utilizou motores de passo. O controle foi realizado utilizando
um controlador PID cujos parâmetros foram levantados a partir da planta do modelo teórico e ajustados pelos dados
empíricos de testes. A planta do sistema foi simulada e analisada via Matlab utilizando a ferramenta PID tuner. Sendo
a estrutura do robô projetada no software Solid Edge.
